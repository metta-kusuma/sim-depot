# SIM Depot (Sistem Informasi Manajemen Depot)

Aplikasi berbasis web untuk mengelola operasional manajemen depot secara efisien. Proyek ini dibangun menggunakan **PHP Native** dan **MySQL** sebagai basis datanya.

## 🚀 Live Demo
Anda dapat mencoba langsung aplikasi yang sudah aktif secara online melalui tautan berikut:
👉 [Buka Live Demo](http://sipamis.fwh.is)
